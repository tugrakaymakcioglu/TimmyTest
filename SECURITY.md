# Security Policy 🔒

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in TimmyTest, please do NOT open a public issue. Instead, report it privately to the maintainers or use GitHub's private vulnerability reporting feature.

We aim to respond to security vulnerability reports within 48 hours and provide patches promptly.
